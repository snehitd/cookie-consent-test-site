How to Use This Page

  1. Visit any other page on this site to let tracking scripts set cookies.
  2. Return here (or refresh). All cookies set during that session appear in the table above.
  3. Use the category filter buttons to focus on Analytics, Marketing, Functional, or Others.
  4. Use Delete on any row to remove a specific cookie — useful for testing what the consent banner does on first visit, or for verifying that the enforcement branch correctly deletes cookies on rejection.
  5. After deleting, go back to the relevant page to confirm the cookie gets re-set.
