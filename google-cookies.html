About Google Analytics, Tag Manager & Advertising Cookies

Google Analytics 4 (GA4) is Google's web analytics platform. It loads a JavaScript tag (gtag.js) that tracks user behaviour — page views, scroll depth, clicks, conversions — and reports to a GA4 property identified by a Measurement ID (format: G-XXXXXXXXXX). GA4 sets first-party cookies to persist a client ID and session state across page views. A single domain can send data to multiple GA4 streams simultaneously; each stream gets its own session companion cookie (_ga_<ID>) while the client ID (_ga) is shared.

Google Tag Manager (GTM) is a tag management system that loads a single container script (gtm.js). That container then fires other tags — GA4, Google Ads, Conversion Linker, Meta Pixel, and more — based on configurable triggers and variables. GTM itself does not set any cookies directly; its published tags do. This means the cookie footprint of a GTM-enabled page depends entirely on which tags are live in the GTM dashboard.

Google Ads & Conversion Linker — Google Ads conversion tracking measures actions taken on a site after a visitor clicked a Google paid ad. The Conversion Linker tag (a built-in GTM tag type) is the mechanism that bridges the ad click to the on-site conversion: it reads the gclid URL parameter appended by Google Ads and stores it in first-party cookies (_gcl_au, _gcl_aw) so it can be read even if third-party cookies are blocked.

Google AdSense / Ad Manager (GAM) serves display ads on publisher websites. When an ad renders, the browser makes requests to doubleclick.net which sets third-party cookies on that domain for ad targeting, frequency capping, and cross-site reach measurement. These cookies cannot be set by our site's own scripts — they require a real ad slot loading gpt.js from Google's servers.

Five ways Google cookies get set on a website

  1. GA4 direct tag (gtag.js) — first-party: Include the GA4 async script and call gtag('config','G-XXXX'). Cookies _ga and _ga_<ID> are written on first page load and updated on each subsequent visit.
  2. Google Tag Manager (GTM) — first-party via tags: The GTM container loads and fires published tags. GA4 cookies appear through Tag 1; Conversion Linker cookies through Tag 9. No cookies are written if the container has no live tags.
  3. GTM Conversion Linker — first-party: Fires on every page load and writes _gcl_au (conversion linker token) and gtm-session-start (session marker). If the URL contains a gclid= parameter, also writes _gcl_aw (Google Ads click ID) for cross-device attribution.
  4. Google Ads conversion tag — first-party: Requires a Google Ads account and an AW-XXXXXXXXX conversion ID. Reinforces _gcl_au and sets _gcl_aw. Also enables remarketing audience lists.
  5. AdSense / GAM ad slot — third-party: A GPT ad slot loads gpt.js, which fetches ads from doubleclick.net. The ad server response sets IDE, DSID, and other cookies directly on the doubleclick.net domain — never on our origin.

Google Consent Mode v2 — How It Gates These Cookies

Consent Signal Cookies Gated Behaviour When Denied
analytics_storage _ga, _ga_<ID> GA4 still sends pings but uses cookieless modelling; no client ID stored
ad_storage _gcl_au, _gcl_aw Conversion linker and click ID cookies not written; conversions modelled
ad_user_data (no cookie; signal only) User data not sent to Google Ads for audience building
ad_personalization (no cookie; signal only) Remarketing and personalised ads disabled
functionality_storage Site functional cookies (not Google-set) Not applicable to Google scripts
